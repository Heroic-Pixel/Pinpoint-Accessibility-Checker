Interactive component fixtures

Use this page to test Pinpoint's Interaction observer. Each section has a working version and a broken version of the same component.

  1. Load Pinpoint with the button below. It loads accessibility-checker.js straight from this folder, so you don't need to rebuild first.
  2. Open Inspector → Interaction observer and select Start observing.
  3. Use each component, with the keyboard where you can. Open it, press Tab inside it, close it with Escape. Compare the cards Pinpoint shows with the “Expect” notes.
